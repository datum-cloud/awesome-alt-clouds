## What makes Conecto different

Conecto is a back office built to be operated by an AI agent rather than by people clicking through SaaS screens. It exposes 582 tools across 52 business areas, including CRM, email, phone, calendar booking, invoicing, bookkeeping, help desk, HR, e-signature, forms, newsletters, social posting and hiring, and any agent that can read a link or use a connector (Claude, ChatGPT, Grok and others) can call them. An agent connects in one of three ways: by reading `conecto.chat/SKILL.md` and signing itself up with a single API call, by adding Conecto as an MCP server, or through a REST API with an OpenAPI spec for your own code, Copilot Studio or Power Automate.

Conecto hosts the stack behind those tools (servers, database, phone lines, mail, file store, PDF service and MCP servers), so the business installs nothing. Where a business already runs HubSpot, Salesforce, Microsoft 365 or Google Workspace, the agent can work in those systems through Conecto and the records stay there; other REST systems can be added on an allow-list, and Okta or Entra ID can manage people.

Guardrails are part of the product: every call is logged with the key that made it and what it cost, each key has a daily spending budget, the account has a monthly ceiling, and risky calls such as refunds or deletions can be set to wait for a person's approval. Its terms say records are kept in a database in Frankfurt, Germany, and calls run on servers in Belgium, with some areas using providers elsewhere, including the United States. Conecto is run by CherryWave LLC.

## Pricing model

There is no subscription. The agent tops up one prepaid USD balance and each tool call is paid from it; the per-call price is shown for every tool, and the homepage [pricing section](https://conecto.chat/#pricing) summarises the model:

- **Free start**: $1 of credit on signup.
- **Top-ups**: from $5.
- **Record changes**: $0.01 per change to a record.
- **Reads**: free up to 1,000,000 a month.
- **Failed calls**: cost nothing.

Some areas carry fixed charges, such as $0.25 to send an invoice or $5.00 a month to keep a help center public. The homepage works through a sample month for one person, putting CRM, help desk, scheduling, e-signature and accounting work at $38.00 on Conecto against $98.00 for five separate SaaS subscriptions. Paying per action instead of per seat is the main departure from conventional business software pricing.

## When it fits

- Small businesses that want Claude, ChatGPT or another agent to handle invoicing, bookings, support email and CRM updates
- Developers building agents that need hosted business primitives (CRM, inbox, phone, invoices) behind one key and one balance
- Teams that want their agent to work inside existing HubSpot, Salesforce, Microsoft 365 or Google Workspace data with approval gates on risky actions
- Businesses with light or uneven usage that would rather pay per call than per seat

## When it doesn't

- Teams that want staff to work in a traditional point-and-click CRM or help desk rather than through an AI agent
- Buyers looking for general cloud infrastructure (compute, storage, networking); Conecto is a set of hosted business tools
- Organizations that need every area's data kept strictly inside the EU, since some areas use providers elsewhere, including the United States

## Inclusion criteria

Conecto meets all 3 inclusion criteria: transparent pay-per-call pricing in the homepage [pricing section](https://conecto.chat/#pricing), with prices listed per tool; self-service signup with $1 of free credit at [conecto.chat/account/signup](https://conecto.chat/account/signup) (or by an agent through the API); and a public status page at [status.conecto.chat](https://status.conecto.chat/) reporting uptime for conecto.chat and api.conecto.chat, although it is not linked from the main site.
