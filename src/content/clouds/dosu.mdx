## What makes Dosu different

Dosu is not a traditional cloud infrastructure provider; it is an AI documentation and knowledge automation platform designed to sit on top of your existing development stack. Unlike hyperscalers that provide raw compute or storage, Dosu focuses on the "knowledge layer" for engineering teams and AI agents. Its core differentiator is the ability to automatically capture, maintain, and share institutional knowledge without requiring manual updates from developers.

The platform operates by integrating directly into the tools engineers already use, such as GitHub, GitLab, Slack, and Microsoft Teams. Through its MCP (Model Context Protocol) Server, Dosu connects to coding agents (like Cursor or Windsurf) to provide consistent, token-efficient context. This ensures that AI agents are working with up-to-date best practices rather than legacy patterns or hallucinated information. By syncing with existing documentation sources like Notion or Confluence, Dosu eliminates the need for data migration while ensuring that documentation stays fresh via automatic reviews triggered by code changes.

Dosu also introduces the concept of "Public Spaces" for open-source maintainers, allowing them to share knowledge bases that guide contributors and reduce triage overhead. This shifts the paradigm from passive documentation repositories to active, living knowledge infrastructure that accelerates both human collaboration and agent performance.

## Pricing model

Dosu operates on a subscription-based model with a distinct tier structure for different user types.

*   **Free Tier:** Available for individual developers and public repositories. This includes access to Dosu’s Public Spaces, which contain knowledge about hundreds of open-source tools.
*   **Team/Enterprise Plans:** While specific dollar amounts are not publicly listed on the homepage, the platform offers paid tiers for engineering teams requiring private knowledge bases, advanced integration features, and SOC 2 Type II certified security compliance.

The value proposition centers on reducing AI token costs and engineering toil. By providing accurate context, Dosu claims to reduce the number of tokens burned by AI coding agents, leading to faster agent runs and lower API costs for LLM providers. This stands out from typical cloud pricing, which charges for resources consumed, whereas Dosu charges for the intelligence and efficiency gained from structured knowledge.

## When it fits

*   **Teams using AI Coding Agents:** Organizations using tools like Cursor, GitHub Copilot, or other MCP-enabled agents need consistent context to reduce hallucinations and token usage.
*   **Engineering Leaders concerned with Bus Factor:** Teams looking to automate knowledge transfer and ensure documentation never goes stale without adding manual maintenance toil.
*   **Open Source Maintainers:** Projects that want to automate issue triage, guide contributors, and provide a public knowledge base to reduce duplicate questions.
*   **Companies with Existing Doc Stacks:** Teams using Notion, Confluence, or GitHub Wikis who want to sync and enhance existing documentation without migrating data.

## When it doesn't

*   **Infrastructure Needs:** This provider does not offer compute, storage, networking, or database services, making it a poor fit for teams seeking raw cloud infrastructure.
*   **Non-Developer Workflows:** The platform is tightly coupled with developer tools (Git, Slack, IDEs) and may not provide value for non-technical departments or workflows unrelated to software development.
