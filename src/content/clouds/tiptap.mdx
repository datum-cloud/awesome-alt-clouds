## What makes Tiptap different

Tiptap is not a traditional infrastructure cloud provider; it is a specialized developer platform for building rich text editing experiences. Unlike hyperscalers that offer general-purpose compute and storage, Tiptap provides a headless, open-source editor framework built on ProseMirror. This allows developers to retain full control over the UI and data structure while leveraging a robust ecosystem of 100+ extensions.

The platform distinguishes itself through its "AI Toolkit," which enables the creation of AI agents that can directly edit documents in real-time. This goes beyond simple text completion, allowing for complex workflows like multi-document processing, proofreading, and chatbots that modify content based on context. Additionally, Tiptap’s collaboration layer, powered by Hocuspocus, supports live cursors, offline editing, and conflict resolution, features that are often difficult to implement from scratch on generic cloud infrastructure.

## Pricing model

Tiptap operates on a mixed pricing model. The core editor framework is MIT-licensed and free to use. However, advanced features such as real-time collaboration, document conversion, comments, and the AI Toolkit are available through paid plans on the Tiptap Platform. The platform offers a self-service signup for immediate access to these features, with transparent pricing tiers visible on their website. They also offer an Enterprise option for teams requiring SOC 2 Type II compliance, GDPR adherence, and EU hosting options.

## When it fits

- Building SaaS applications that require complex, collaborative rich text editing.
- Teams wanting to integrate AI-driven document editing without building custom LLM pipelines.
- Developers seeking a headless solution to maintain full UI/UX control.
- Projects requiring real-time collaboration features (live cursors, presence) out-of-the-box.

## When it doesn't

- General-purpose cloud infrastructure needs (compute, storage, networking).
- Workloads requiring broad geographic data center availability for low-latency global access.
