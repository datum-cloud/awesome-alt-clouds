## What makes Upsun different

Upsun (formerly Platform.sh) distinguishes itself through a strict Git-driven automation model that treats infrastructure as code. Rather than managing static servers, developers push to a repository to trigger the creation of ephemeral, fully isolated environments for every branch or pull request. This "preview environment" capability allows teams to test complex application stacks—including databases, caching layers, and background workers—in seconds, significantly reducing integration conflicts and deployment risks.

The platform is designed for high-complexity applications, particularly those requiring multi-site management or heavy CMS/eCommerce workloads like Drupal, Magento, and Next.js. Upsun supports a multi-cloud strategy, allowing applications to be deployed across different cloud providers or edge locations from a single configuration, avoiding vendor lock-in while maintaining consistent development and production parity.

## Pricing model

Upsun operates on a subscription-based model rather than a pure pay-as-you-go structure. Pricing is tiered based on "credits" or resource units, which determine the number of concurrent environments, storage limits, and compute power available. While specific dollar amounts are not listed on the main public pages, the pricing calculator on their site allows users to estimate costs based on team size and environment count. This model favors teams that value predictable monthly billing and the ability to spin up numerous temporary environments without fear of unexpected usage spikes, contrasting with the granular metering of hyperscalers.

## When it fits

- **CMS and eCommerce Teams:** Organizations running Drupal, Magento, WordPress, or Shopify Plus that need robust staging and multi-site management.
- **Agile Development Teams:** Groups that benefit from instant, isolated preview environments for every code change to accelerate CI/CD pipelines.
- **Compliance-Heavy Industries:** Enterprises in government, finance, or healthcare requiring ISO 27001, SOC 2, and HIPAA compliance out of the box.
- **Multi-Cloud Strategies:** Teams wanting to abstract infrastructure from specific cloud providers using a unified PaaS layer.

## When it doesn't

- **Static/Serverless Workloads:** Simple static sites or serverless functions are better suited for lower-cost platforms like Vercel or Netlify.
- **Custom Infrastructure Needs:** Projects requiring deep, low-level control over networking, kernel settings, or custom VM configurations will find the PaaS abstraction limiting.

## Inclusion criteria

Upsun meets all three inclusion criteria:

1.  **Transparent Pricing:** A pricing calculator is available on the website to estimate costs.
2.  **Self-Service Signup:** Users can start a free trial directly via the authentication portal.
3.  **Public SLA/Status:** The Trust Center and documentation outline compliance certifications (SOC 2, ISO 27001) and support SLAs.
