## What makes OpenComputer different

OpenComputer describes itself as "the open source alternative to Devin": a cloud coding agent that a team works with in Slack by mentioning `@Computer` in a channel. The agent reads the code, runs commands, builds and tests, and opens a pull request, posting its progress in the thread; UI changes come with a screenshot and a preview link. The product is built for multiplayer use: anyone in the thread can steer the work, conventions one person explains apply to later requests, and the thread records who asked for each change. Slack is the first-class interface, with a web dashboard, API and CLI also available.

The code is Apache-2.0 on GitHub, and the whole stack can be self-hosted on one VM per organization in your own AWS, Azure or Google Cloud account. The VM connects out to a gateway and needs no open inbound ports. Each Slack thread gets its own session and copy of the repositories, so one VM can often run hundreds of sessions; state is written to the VM's local disk first and persisted to a git-backed store, so another VM can pick up a session and you scale out by adding VMs. Heavy builds and preview environments can be delegated to an external sandbox rather than giving every session its own.

Under the hood each session runs an existing agent (Claude Code, Codex or OpenCode), and teams can bring their own Claude or ChatGPT subscription or an API key instead of paying for model tokens. OpenComputer's own benchmark puts its time from Slack message to first push at 24 seconds, against 53–72 seconds for the other cloud coding agents it tested, including Devin.

## Pricing model

Hosted plans are published on the homepage [pricing section](https://opencomputer.dev/#pricing) and cover a whole Slack workspace, billed by "work minutes": the time the agent is actively working, metered by the second, with idle and waiting time free.

- **Trial**: free for 3 days or 600 work minutes, whichever comes first; no card, includes $10 of OpenComputer's model tokens.
- **Pro**: $20/month for 2,000 work minutes.
- **Max**: $200/month for 25,000 work minutes.
- **Enterprise**: custom volume pricing for over 60,000 work minutes a month.
- **Self-hosted**: free under Apache-2.0; you pay your cloud and model provider.

Minutes past a plan's allowance cost $0.01 each, paid from prepaid credit packs of $10, $50 or $200 with optional auto top-up. Models are either your own subscription or key at no charge, or OpenComputer's tokens at API prices with no markup. Billing for the agent's working time, rather than per seat or per sandbox hour, is the notable difference from most hosted dev environments.

## When it fits

- Teams that want to hand off bug fixes and small features from Slack threads and get pull requests back
- Organizations that want a Devin-style cloud agent but need to run it inside their own AWS, Azure or Google Cloud account
- Teams that already pay for Claude or ChatGPT subscriptions and want to reuse them for cloud agents
- Mixed technical and non-technical teams that want to request and steer changes in a shared thread

## When it doesn't

- Teams that don't use Slack as their main collaboration tool, since Slack is the first-class interface
- Buyers looking for general-purpose compute, hosting or sandboxes rather than a coding agent product
- Organizations that need a public status page or published uptime SLA for the hosted service

## Inclusion criteria

OpenComputer meets 2 of 3 criteria: transparent pricing in the homepage [pricing section](https://opencomputer.dev/#pricing) and self-service signup with a no-card trial at [app.opencomputer.dev](https://app.opencomputer.dev/?plan=trial). No public status page or SLA is linked from the site, so the third criterion is not met.
