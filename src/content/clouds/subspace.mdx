## What makes Subspace different

Subspace operates a dedicated, private fiber-optic network designed exclusively for real-time applications rather than general-purpose cloud compute. Unlike hyperscalers that treat networking as commodity infrastructure, Subspace optimizes every layer—routing, packet handling, protocol implementation—for millisecond-sensitive workloads. The platform integrates with 100+ carrier partners (AT&T, Verizon, Orange, Telia, Telstra, Vodafone, and others) to provide deterministic, low-loss paths across continents.

The core differentiator is architectural: Subspace does not provision servers or storage. Instead, it provides managed network services via simple API integration and configuration changes. Applications route traffic through Subspace's optimized network nodes, gaining latency reductions up to 80% and packet loss reduction to 99% without code rewrites.

## Pricing model

Subspace uses usage-based pricing, charging per bandwidth consumed and API calls made. Exact tier details are not publicly listed on the website; pricing is typically provided via custom quote after signup. This reflects the provider's focus on enterprise and high-volume gaming/fintech customers rather than self-service tiers. The model aligns with network infrastructure pricing (metered by throughput) rather than compute-instance pricing, making it fundamentally different from AWS/GCP/Azure.

## When it fits

- **Multiplayer online gaming:** Competitive games where latency variance breaks player experience; Subspace's optimization directly addresses jitter and packet loss.
- **Live voice/video conferencing:** WebRTC and SIP-based applications benefit from prioritized real-time protocol handling and global routing.
- **Fintech with low-latency requirements:** Trading platforms, payment processing, and risk systems that cannot tolerate network delays.
- **Live streaming and sports betting:** Applications where sub-100ms latency is a core feature.
- **Global IoT and edge applications:** IoT deployments requiring deterministic, low-loss connectivity across regions.

## When it doesn't

Subspace is not a general-purpose cloud platform. It offers no compute, storage, or traditional IaaS services—only network infrastructure. Organizations seeking serverless functions, databases, or object storage should pair Subspace with a primary cloud provider. Small projects or development environments with latency-insensitive workloads do not justify the cost.
