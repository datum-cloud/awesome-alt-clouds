## What makes Subconscious different

Subconscious is not a general-purpose cloud — it's an inference layer designed specifically for agentic workloads that run far longer than a typical chatbot turn. Rather than serving open models as-is, it wraps them with a custom runtime that performs on-GPU context compression as an agent's context grows, pruning less-relevant steps while preserving accuracy, and freeing GPU memory so long runs don't slow down or degrade mid-task.

The platform pairs this compression with hyper-efficient caching: when context is pruned, prefix and suffix segments are reused rather than recomputed, keeping cost and latency flat even deep into multi-hundred-step agent runs. Models served through Subconscious carry a "Marathon" suffix (GLM-5.3 Marathon and DeepSeek V4.1 1017 Marathon), signaling they've been tuned to sustain performance across contexts extending past 200k tokens and up to 5M+ tokens — well beyond what standard open-model inference stacks (e.g., vanilla vLLM/SGLang deployments) handle efficiently.

Unlike hyperscaler AI services that optimize for single-shot latency and general workloads, Subconscious explicitly treats long-horizon, multi-step agent execution as the primary workload — a narrower but increasingly important niche as coding agents and autonomous product agents become mainstream.

## Pricing model

Pricing is pay-per-token by default (e.g. GLM-5.3 Marathon at $1.40 input / $4.40 output per 1M tokens), with Team Token Plans from $1,000/mo and quoted Dedicated Deployments for larger teams. The differentiator is that _effective_ tokens are billed after runtime compression rather than raw context size. The company publishes a comparative example: a "long" agent run with a 750K-token effective context costs $89.11 on Opus 5.5 and $80.69 on standard GLM-5.3, versus $27.56 on GLM-5.3 Marathon via Subconscious — 3.2x less than Opus and 2.9x less than standard GLM-5.3 inference, achieved by billing ~96.2M tokens instead of ~281.6M. Exact per-token rates by model are listed on the [pricing page](https://www.subconscious.dev/pricing). The standout is that savings scale with context length — the longer and more complex the agent task, the bigger the discount versus standard inference.

## When it fits

- Coding agents (Claude Code, Codex, OpenCode, GitHub Copilot) that run extended multi-step sessions
- Product/workflow agents (e.g. built on LangChain, or any OpenAI/Anthropic-compatible client) needing long context retention
- Teams already using open models (GLM, DeepSeek) wanting a drop-in faster/cheaper inference backend
- Workloads exceeding 200k tokens of context where standard inference costs and latency balloon
- Enterprises wanting to run the inference stack on dedicated or on-prem GPUs

## When it doesn't

- Short, single-turn chatbot or Q&A workloads with minimal context won't see meaningful benefit from compression.
- Teams requiring proprietary frontier models (e.g., GPT-4/Claude/Gemini directly) rather than open-weight models.
