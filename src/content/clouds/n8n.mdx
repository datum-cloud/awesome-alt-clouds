## What makes n8n different

n8n is an **open-source, permissively-licensed workflow automation platform** designed for technical teams who want control and transparency. Unlike Zapier or Make, which are closed SaaS platforms, n8n publishes its source code under a fair-code license (source-available, not open-source in the GPL sense), allowing self-hosting on your own infrastructure while offering optional cloud hosting.

The platform prioritizes **visual workflow building with deep code capabilities**—you can mix low-code node logic with JavaScript when needed. A distinguishing feature is traceability: every step of an AI agent's reasoning is visible on the canvas, making debugging and auditing transparent. The visual editor supports unlimited workflow logic without restrictive pricing tiers, contrasting with competitors that meter features.

With 191k GitHub stars and 500+ integrations, n8n appeals to DevOps, security ops, and backend teams automating internal processes, IT onboarding, incident enrichment, and RAG-powered AI applications.

## Pricing model

n8n offers a **hybrid freemium + subscription model**:

- **Free tier**: Available on both cloud (n8n Cloud) and self-hosted versions. Includes basic workflow execution, limited integrations, and community support.
- **Paid cloud tiers**: Subscription-based plans (Professional, Business, Enterprise) with per-seat or usage-based metering. Exact pricing not publicly detailed in the page content, but models typically include execution limits, advanced features (SSO, audit logs), and priority support.
- **Self-hosted**: Perpetually free under the fair-code license; you host on your own infrastructure (Docker, Kubernetes, etc.). Enterprise features available via paid licensing for self-hosted deployments.

This model stands apart because **self-hosting eliminates vendor lock-in and per-execution billing**—you pay infrastructure costs, not per workflow run, making it cost-effective for high-volume automation.

## When it fits

- **Internal workflow automation** at technical companies (IT onboarding, incident response, data pipeline automation).
- **AI agent development** requiring transparent, auditable reasoning flows.
- **Security & ops teams** building custom automation without SaaS vendor constraints.
- **Organizations with data residency or compliance requirements** needing self-hosted control.
- **High-volume automation** where per-execution SaaS pricing becomes prohibitive.

## When it doesn't

- **Non-technical end-users**: n8n targets developers and technical teams; it lacks the drag-and-drop simplicity of Zapier for business users.
- **Minimal customization needs**: If you only need pre-built Zapier-style automation, simpler low-code platforms may be faster to adopt.

## Open source

n8n is **source-available under the fair-code license** (not open-source GPL). The full codebase is public on GitHub (191k stars), allowing inspection and community contributions. You can self-host and modify it, but commercial redistribution requires a license. This balances transparency with sustainable development.
